MIDNIGHT VAULT is a top-down 2D heist game: sneak past guards with sweeping vision cones, blind the security cameras with EMP pulses, lift the loot and slip out the getaway door — across three rooms of rising difficulty, all drawn and sounded with code, no network needed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
